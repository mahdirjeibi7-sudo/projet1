# Gestion des tâches – Application Python

Projet 1 du module **Outils collaboratifs avec Git / GitHub** (Licence 1, S1).

Petite application en console qui permet de gérer des tâches quotidiennes.
Chaque tâche possède un numéro et un titre.

## Fonctionnalités

| Menu | Action |
| --- | --- |
| 1 – Ajouter une tâche | Demande le titre, refuse une saisie vide, ajoute la tâche |
| 2 – Afficher les tâches | Affiche les tâches numérotées, ou un message si la liste est vide |
| 3 – Rechercher une tâche | Affiche les tâches dont le titre contient un mot-clé |
| 0 – Quitter | Ferme le programme ; toute autre option affiche une erreur |

## Exécution

1. Ouvrir le dossier du projet dans **VS Code**.
2. Ouvrir le fichier `main.py`.
3. Cliquer sur le bouton **Run Python File** (triangle en haut à droite).
4. Utiliser le menu dans le terminal de VS Code.

## Étapes réalisées

1. Création du programme `main.py` et test avec « Run Python File ».
2. Initialisation du dépôt Git local (`git init`).
3. Commits successifs : programme, documentation, fichier `.gitignore`.
4. Création d'un dépôt GitHub vide et liaison avec `git remote add origin`.
5. Premier envoi avec `git push -u origin main`.
6. Mise à jour du README, nouveau commit et second `git push`.
